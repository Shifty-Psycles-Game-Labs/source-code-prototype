One engine. Any world your rules can survive.

NEM-U is a simulation engine built on a simple discipline: separate what's proven, what's conjectured, and what's designed — then let every world you build inherit consistent rules from whichever layer it draws on.

Built to run light

Targeting a decade-old mid-range PC as the baseline, not the ceiling. Fidelity is a dial, not a requirement.

Built to be honest

Every rule in a NEM-U world is tagged by how well-founded it is — so players and builders always know what's load-bearing.
