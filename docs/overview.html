Overview

What NEM-U actually is

A simulation engine for exploring fictional universes, historical periods, or physical systems with rules that hold together — because every rule is built on a clearly labeled foundation, from settled physics up to open-ended design.

Most world-building tools ask you to choose between rigor and flexibility. NEM-U keeps both, by never letting the two kinds of claim blur together.

Under the hood, NEM-U is a single mathematical structure — a manifold — carrying several layers of rules at once. Each layer has a different epistemic status, and that status is explicit everywhere it's used: in the engine, in the documentation, and eventually in the tools a builder uses to design a world.

Three tiers, one manifold

  • 01
    established physics

    The physical layer

    A discrete geometric operator — a Hodge Laplacian over a simplicial mesh — used to unify Maxwell's equations and linearized general relativity on the same footing. This layer answers to standard mathematical physics and is held to that standard.

  • 02
    conjectural

    The cognitive layer

    A tensor bundle representing knowledge, emotion, intent, and action as coupled fields with gradient-flow dynamics. This is a working hypothesis about how to give simulated minds consistent, non-scripted behavior — not an established result.

  • 03
    design layer

    The rules-and-magic layer

    A formally defined pair of mechanisms for anything a world calls "magic" or "impossible technology": one that reweights probable outcomes directly, and one that only works through an in-world causal chain. Explicitly a design choice, not a claim about how reality works.

Keeping these labeled and separate is the actual point. A rule that looks magical but is secretly load-bearing physics — or the reverse — is where most systems quietly become inconsistent. NEM-U treats that as a bug category and designs against it from the ground up.

Design commitments

Runs on modest hardware

Reference target is a mid-range PC from around 2016 — an i5-6400, 16GB RAM, a 2GB GTX 960. Simulation fidelity — step count, level of detail — is a tunable dial, not a fixed cost.

Derived, not stipulated

Wherever possible, rules are derived from a minimal set of axioms rather than declared outright. The axioms that remain are flagged explicitly, so the irreducible assumptions are always visible.

Built in the open, shared in parts

The engine and full source live in a private repository while the project is in active development. Public pages like this one share the architecture and reasoning, not the implementation.

For artists and researchers alike

The same manifold that renders a game world is meant to be legible enough to use as a lightweight research or teaching tool — without requiring a physics background to get started.
